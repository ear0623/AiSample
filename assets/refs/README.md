# 레퍼런스 이미지

배치 예시(`assets/example_batch.json`)가 참조하는 폴더입니다.
직접 찍은 사진이나 생성한 콘셉트 이미지를 여기에 넣으세요.

권장 조건:
- 피사체가 화면의 60% 이상
- 배경 단순, 그림자 없는 균일 조명
- 512×512 이상, 20MB 이하 (PNG/JPEG/WebP)
- 정면 또는 3/4 뷰 1장이면 충분. 여러 각도가 있으면 `multiview-to-model` 사용

개인 작업물/저작권 있는 이미지는 이 폴더에 커밋하지 마세요(`.gitignore`에 `assets/refs/*` 규칙이 없으므로 주의).
